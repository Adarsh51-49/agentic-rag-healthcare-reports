# Current limitations

1. Only 46 articles and 15 evaluation questions were used.
2. The corpus focuses on AI in healthcare, limiting generalisation.
3. Retrieval quality does not itself demonstrate answer correctness.
4. The NLI verifier and three LLM judges can make mistakes or disagree.
5. Condition C combines retrieval, roles, checking and revision, creating a
   confound when it is compared with A or B.
6. Automated evaluation does not replace human evaluation.
7. Generation time depends on free Colab availability and hardware.
8. The prototype is not clinically validated and must not provide clinical advice.
9. A live demo run is not part of the frozen formal evaluation.
10. Full public release requires data and licence review.
